# Security

This repository is an **unofficial fork** of
[NVIDIA/soma-retargeter](https://github.com/NVIDIA/soma-retargeter). It is not
maintained or supported by NVIDIA — please do not report issues in this fork
through NVIDIA's security channels.

To report a security issue in this fork, contact the repository maintainers
privately rather than opening a public issue. For vulnerabilities in the
upstream project, follow the upstream repository's security policy.
